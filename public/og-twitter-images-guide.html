OG & Twitter Images Guide for CheekoAI

This guide outlines the specifications and content requirements for the missing social media preview images.

1. Open Graph Image (og-image.jpg)

Dimensions: 1200 x 630 pixels
Format: JPG
File size: Keep under 1MB
Location: /public/og-image.jpg

Content Requirements:

  • CheekoAI logo prominently displayed
  • Tagline: "AI Learning Companion for Children"
  • Visual of the AI toy (Cheeko character)
  • Bright, playful colors (orange #f36e24 as primary)
  • Age range indicator: "Ages 4+"
  • Trust badges: "COPPA Compliant" and "Safe AI"
  • Clean, modern design that appeals to parents

2. Twitter Image (twitter-image.jpg)

Dimensions: 1200 x 675 pixels (16:9 ratio)
Format: JPG
File size: Keep under 1MB
Location: /public/twitter-image.jpg

Content Requirements:

  • Similar design to OG image but optimized for Twitter's format
  • CheekoAI logo and branding
  • Clear, readable text even at smaller sizes
  • Call-to-action: "Join the AI Learning Revolution"
  • Website URL: cheekoai.in
  • Visual elements showing educational aspects

Design Tips:

  • Text Hierarchy: Ensure main message is readable even when image is displayed at smaller sizes
  • Brand Consistency: Use the same orange (#f36e24) and design elements from the website
  • Safe Zones: Keep important content away from edges (at least 60px padding)
  • Test Preview: Use Facebook's Sharing Debugger and Twitter Card Validator to test

Quick Creation Tools:

  • Canva (has OG/Twitter image templates)
  • Figma (for precise control)
  • Adobe Express (free templates available)

Note: These images are crucial for SEO and social media engagement. They appear when your website is shared on social platforms and can significantly impact click-through rates.
